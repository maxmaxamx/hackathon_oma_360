* **Общие параметры запроса:**
* URL эндпоинта: `[https://www.oma.by/api-v2/catalog/products/search/fast](https://www.oma.by/api-v2/catalog/products/search/fast)`.


* HTTP-метод: `GET`.


* Формат данных: `application/json`.




* **Параметры строки запроса (Query String):**
* `q` (`String`, обязательный): строка поискового запроса (например, `"ламинат"`).


* `index` (`String`, обязательный): область поиска каталога (значение `"catalog"`).


* `limit` (`Integer`, опциональный): максимальное число элементов в ответе (в примере `300`).


* `city_id` (`Integer`, опциональный): идентификатор выбранного города (в примере `8019`).


* `location_id` (`Integer`, опциональный): идентификатор склада/региональной точки (в примере `432550`).




* **Заголовки запроса (Headers):**
* `Accept`: `application/json`.


* `Referer`: `[https://www.oma.by/](https://www.oma.by/)` (базовый адрес источника).


* `X-Bitrix-Csrf-Token`: CSRF-токен сессии Bitrix.


* `Cookie`: идентификатор города и сессионные куки (`BITRIX_SM_GEOIP_CITY_ID=8019`, `PHPSESSID`).




* **Структура тела ответа (Response JSON):**
* `status`: статус ответа (`String`, значение `"success"`).


* `data.count`: общее количество найденных позиций (`Integer`, в примере `202`).


* `data.query_id`: уникальный UUID поисковой выборки для сквозной аналитики и пагинации.


* `data.suggest`: массив сопутствующих поисковых подсказок (`Array of Strings`).


* `data.items`: массив найденных товаров (`Array of Objects`).




* **Спецификация полей товара (`data.items[]`):**
* `id`: идентификатор товара в каталоге (`Integer`).


* `name`: наименование товара (`String`, содержит HTML-теги `<b>` для подсветки запроса, требует очистки от тегов).


* `link`: относительный URL карточки товара на сайте (`String`).


* `picture`: относительный URL миниатюры изображения товара (размер `250x250`).


* `catalog.price`: текущая цена продажи (`Float`).


* `catalog.base_price`: цена без скидки (`Float` или `null`).


* `catalog.is_discount`: флаг наличия скидки (`Boolean`).


* `catalog.measure`: единица измерения (`String`, например `"шт"`).


* `catalog.available`: статус наличия товара (`Boolean`).


* `catalog.cart.inc`: кратность добавления товара в корзину (шаг упаковки) (`Integer`).

### Подводные камни и особенности работы (для ботов и агентов):

1. **Защита HosterGuard (Anti-bot / WAF):**
   * При первом обращении сервер возвращает HTTP 200 со страницей верификации `<title>Verification</title>` (`Server: HosterGuard`) и кукой `hg-client-security`.
   * Из встроенного `<script>` нужно извлечь куку `hg-security=...` (живёт 120 сек) и передать её при повторном запросе. **Важно:** значение токена заканчивается на `=` (base64) — не делайте наивный `split('=')`.
   * **Playwright / Puppeteer:** скрипт верификации содержит проверку `if (navigator.webdriver === true)`, из-за чего страница не перезагружается автоматически. Нужно либо маскировать `navigator.webdriver`, либо программно проставлять куку `hg-security`.

2. **Строгая связка `X-Bitrix-Csrf-Token` и `PHPSESSID`:**
   * Без валидного токена API возвращает `200 OK` с ошибкой `{"code": "invalid_csrf", "message": "Invalid csrf token"}`.
   * Токен берётся из HTML-страницы (`'bitrix_sessid': '<32_hex_chars>'` или `BX.bitrix_sessid()`).
   * Токен **жёстко привязан** к сессионной куке `PHPSESSID`. И кука, и заголовок `X-Bitrix-Csrf-Token` должны передаваться совместно из одной сессии.

3. **Особенности параметров:**
   * Без параметра `limit` или при `limit=0` сервер возвращает **8 элементов** по умолчанию. Поддерживает большие лимиты (например, 100+).
   * При пустом `q` отдаётся пустой результат (`count: 0`, `items: []`) без ошибки 4xx.
   * Поле `name` в товарах содержит теги `<b>...</b>` для подсветки совпадений — требует очистки перед использованием в чистом тексте.
